# Study Guide Ranking — Worst to Best

Every study guide in the repo (including `k8s/`), ranked **worst to best** against one criterion: **is this textbook-quality material with broad scope?** Each guide was scored on two axes:

- **Textbook quality** — does it *explain* with prose, motivation, and mental models (vs. bullet-point syllabi, command cheat-sheets, or code dumps with thin commentary)? Pedagogical progression, worked examples, trade-off discussion, accuracy.
- **Breadth of scope** — does it cover the whole subject the title promises, the way a textbook would, or only a slice?

Scores are out of 100. Ties are ordered by judgment on the two axes.

## Summary by tier

- **Bottom tier (40–55): outline-only guides.** Terraform, SvelteKit, Next.js, Django, Vue, and Qt are curricula — broad topic lists with doc links — not teaching material. Kubernetes Security shares the format. These would benefit most from being rewritten in the prose-and-code style of the top tier.
- **Middle tier (55–80): references and catalogs.** Strong, accurate, broad — but reference-grade (Postgres feature reference, the cloud translation guides, Git, Redis, SQLite) or scope-limited (Caddy, Vim, the "for Python devs" bridges).
- **Top tier (80–92): genuine textbook material.** The "Advanced" runtime trilogy (Python/Node/Go), Advanced Linux/Postgres, Distributed Systems, Networking Fundamentals, Observability, LLM App Dev, GitHub Actions, Electron, ESP32, and — best of all — Linux Fundamentals: prose-first, mental-model-driven, broad, and honest about trade-offs.
